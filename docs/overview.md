# Northstar Platform overview

Northstar is a fictional platform for teams that operate application environments across multiple cloud providers. This documentation site is intentionally small, but it uses the same building blocks as a production Docusaurus site: front matter, navigation, cross-links, code blocks, and linting rules.

## What Northstar manages

Northstar stores an **environment definition**: a named collection of infrastructure settings, a deployment profile, and access rules. A platform team creates a reusable profile and applies it to development, staging, and production environments.
